# Omo Space demo

The player page for the [Omo Space](https://github.com/omoresearch/omo-space) demo,
"the whole loop, live" (27 October 2026), served by GitHub Pages:
**https://omoresearch.github.io/omo-space-demo/**

GitHub release files download instead of playing, so the README's demo links here.
`omo-space-demo-720p.mp4` is a 720p H.264/AAC web copy of the
[original 1080p release file](https://github.com/omoresearch/omo-space/releases/tag/demo-2026-10-27),
encoded with faststart so it streams. Chapters come from the
[transcript](https://github.com/omoresearch/omo-space/blob/main/docs/demo/TRANSCRIPT.md).

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
